# minimax-h3-inputs-smarty —— MiniMax H3 素材可选输入

为 ComfyUI 官方 **MiniMax H3 Reference to Video** 节点提供「打包-解析」式可选素材输入：
所有参考素材（图片/视频/音频）**全部可选、不填也能跑**，且支持 手输网址自动下载 /
输入目录下拉选择 / 本地上传 三种选材方式。

---

## 一、解决的问题

官方 `MiniMax H3 Reference to Video` 节点的 `ref_image_0..8`、`ref_video_0..2`、
`ref_audio_0..2` 槽位**一旦连线就必须给定输入**，实际工作中经常只想用其中一两个素材，
却要为其余槽位准备占位数据。

本插件提供两个节点组成「打包 → 解析」链路：

```
MiniMaxH3素材参数可选输入 ──inputs_bundle──▶ MiniMaxH3素材输入包解析
                                                     │
        image_0..8 / video_0..2 / audio_0..2 / prompt / length（空槽位 = None）
                                                     │
                                                     ▼
                              MiniMax H3 Reference to Video（15 条线全部预连好）
```

解析节点对**空槽位输出 None**，官方 MiniMax 节点对 None 引用直接跳过
（`comfy_extras/nodes_minimax_h3.py` 中 `if img is None: continue`），因此所有线
预先连好后，不填素材也能正常运行、不报错。

## 三、节点一：MiniMaxH3素材参数可选输入

分类 `MiniMaxH3`。所有参数从上到下依次为：

| 参数 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| 提示词 | 多行文本（默认 8 行） | 空 | 随包透传给解析节点的 `prompt` 输出 |
| 目标时长(秒) | **float** | 5.0 | 可点输入、左减右加，支持小数（如 5.6）；范围 1–60 |
| 图片1 .. 图片9 | 字符串（可选） | 空 | 对应 MiniMax 的 `ref_image_0..8` |
| 视频1 .. 视频3 | 字符串（可选） | 空 | 对应 MiniMax 的 `ref_video_0..2` |
| 音频1 .. 音频3 | 字符串（可选） | 空 | 对应 MiniMax 的 `ref_audio_0..2` |

每个素材槽位（在节点详情面板中操作）支持四种操作：

1. **手输**：文件名（相对 `ComfyUI\input`、子目录、绝对路径均可）；
   输入 `http(s)://` 网址时，执行时**自动下载到用户上传目录**后使用。
2. **下拉选择**：列出用户上传目录（`ComfyUI\input`）中对应类型的全部文件，
   右侧 `⟳` 按钮实时刷新列表。
3. **上传按钮**：点击弹出系统文件选择器，按槽位类型过滤
   （图片 `image/*`、视频 `video/*`、音频 `audio/*`），上传后自动选中。
4. **预览按钮**：行最右侧，点击弹出**右侧磁吸预览窗**（可拖动、可关闭），
   按槽位类型渲染图片/视频/音频；手输的 http(s) 网址同样可以直接预览。

**输出**：`inputs_bundle`（自定义类型 `MMX_H3_INPUTS_BUNDLE`），内部结构：

```json
{"v": 1, "prompt": "...", "duration": 5.6,
 "slots": {"img_1": {"kind": "image", "path": "文件名或None"}, ...}}
```

## 四、节点二：MiniMaxH3素材输入包解析

分类 `MiniMaxH3`。

**输入**：`inputs_bundle`（来自节点一的输出）。

**输出**（按顺序）：

| # | 输出 | 类型 | 说明 |
|---|---|---|---|
| 0–8 | `image_0..8` | IMAGE | 图片1..9 解析结果；空槽为 None |
| 9–11 | `video_0..2` | IMAGE | 视频1..3 解析出的帧序列；空槽为 None |
| 12–14 | `audio_0..2` | AUDIO | 音频1..3 解析结果；空槽为 None |
| 15 | `prompt` | STRING | 输入节点的提示词 |
| 16 | `length` | INT | 由目标时长换算的帧数 |

**length 公式**（a = 目标时长秒）：

```
length = max(5, round(a * 24)) + (5 - (max(5, round(a * 24)) % 17)) % 17
```

结果始终落在 MiniMax H3 模型的 `17k+5` 帧网格上：

| 目标时长(秒) | length | 实际约 |
|---|---|---|
| 1 | 39 | ~1.6s |
| 5 | 124 | ~5.2s |
| 5.6 | 141 | ~5.9s |
| 10 | 243 | ~10.1s |
| 60 | 1450 | ~60.4s |

**容错**：单个素材加载失败（文件缺失/损坏/格式不支持）只跳过该槽位并输出
`None` + 警告日志，不影响其它槽位与整体运行。

## 五、工作流接线指南

以 `user/default/workflows/spark.json`（输入节点 + MiniMax H3 Reference to Video）
为模板，接线方式：

1. 输入节点 → 解析节点：`inputs_bundle → inputs_bundle`
2. 解析节点 → MiniMax 节点（**槽位名一一对应**）：
   - `image_0..8 → ref_images.ref_image_0..8`
   - `video_0..2 → ref_videos.ref_video_0..2`
   - `audio_0..2 → ref_audios.ref_audio_0..2`
   - `length → length`
   - `prompt → prompt`（可选；不接则直接在 MiniMax 节点上填提示词）
3. 之后**只操作输入节点**：填素材即用，不填即空；MiniMax 侧 15 条线无需再动。

## 六、网络下载说明（URL 选材）

- 读取环境变量 `http_proxy` / `https_proxy`（含大写形式）：**设置了就走代理，
  未设置则直连**。
- 下载失败自动重试 3 次，支持 `Range` 断点续传（`.part` 临时文件）。
- 同一 URL 按 md5 前缀缓存复用（文件名形如 `minimaxh3_<md5前12位>_<原名>`），
  重复执行不会重复下载。

## 7、前端交互说明

- 素材槽位在**选中节点后的详情面板**中操作（与 H3MediaBoard 媒体板同款交互）；
  节点自带的原始字符串控件已隐藏，但值照常保存/随工作流序列化。
- 面板行序与参数一致：提示词、目标时长、图片1..9、视频1..3、音频1..3，
  行与行之间无空隙。
- **窗口高度联动**：拖动节点窗口变高时，多余高度只分配给提示词输入框
  （其余参数保持固定高度，不会出现下方空白）。
- 文件列表初始为服务器启动时的快照，上传后自动补入，`⟳` 可随时刷新。
- 每行最右侧 `预览` 按钮打开**右侧磁吸预览窗**：固定在屏幕右缘，可拖动、
  可关闭；图片/视频/音频按槽位类型渲染（本地文件经插件路由流式提供，
  http(s) 网址由浏览器直接加载）。

## 九、已知限制

- 视频参考要求 ≥5 帧（官方节点限制），过短视频会由官方节点报错。
- 下拉列表为 input 目录根层文件；子目录文件请手输相对路径（如 `sub/xx.mp4`）。
- 面板 UI 依赖前端 1.49.6 的 DOM widget 渲染（本便携版已满足）。
